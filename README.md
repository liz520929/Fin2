# MONEY LAND 理財樂園

可直接上傳 GitHub 並部署到 Vercel 的手機版 PWA 記帳 App。

## 功能
- 本月收入、支出與可用金額
- 每日記帳與分類
- 預算設定
- 貸款及信用卡餘額
- 年度支出預備金
- CSV 匯出
- 本機自動儲存
- 可加入 iPhone 主畫面

## 部署到 GitHub
1. 在 GitHub 建立新的 repository。
2. 將此資料夾內所有檔案上傳到 repository 根目錄。
3. 到 Vercel 選擇「Add New Project」。
4. 匯入這個 GitHub repository。
5. Framework Preset 選「Other」。
6. 不用填 Build Command，直接 Deploy。

## 注意
資料保存在瀏覽器 localStorage，換手機或清除瀏覽器資料後不會自動同步。
